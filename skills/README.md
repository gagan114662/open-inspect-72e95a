# skills

Playbooks distilled from `docs/self-improvement-archive.jsonl`, one per policy topic, regenerated by
`scripts/distill-skills.py`. Each skill says what the class of problem looks like (the review
findings that were filed under it), how often it recurred, and, where a round recorded it, how it
was fixed. Load the skill whose topic matches the change you are about to make.

Generated files; edit the archive or the policy, not these.
